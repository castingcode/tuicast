Getting started takes about 15 minutes:

1. [Install](installation.md) the TUICast driver and reference TUI.
2. Start the [reference TUI](reference-tui.md), a practice terminal application
   that ships with TUICast.
3. Follow the guide for your language to automate a login:
   [Go](go.md), [Python](python.md), [TypeScript](typescript.md), or
   [Java](java.md).

Each language guide is self-contained, so you can skip step 2 and follow it
directly.
